# WTLST V1

Portable Node.js deployment. Run `npm start`. No runtime packages required.

The complete editable React, SQL and email-function source is included in `wtlst-source.zip`. `assets.json` is the prebuilt website.

Environment: SUPABASE_URL, SUPABASE_ANON_KEY, SITE_OPERATOR, PRIVACY_CONTACT. Email and database setup must be completed before applications open. Never put service keys in this repository.
